# Scripts

This directory is reserved for small administrative and validation scripts used in the homelab.

## Script standards

- Keep scripts readable and commented.
- State the purpose and expected output at the top of each file.
- Avoid storing secrets or credentials.
- Prefer read-only validation scripts when practical.
- Test scripts in the lab before documenting them as complete.

## Planned script categories

- Service-status checks
- User and group inventory
- Resource inventory
- Network configuration checks
- Documentation helpers
